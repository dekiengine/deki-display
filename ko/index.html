deki-display

Deki 자체 디스플레이 라이브러리. 취미용 보드에서 흔히 쓰는 화면을 구동하고, 터치를 읽고, 모든 프레임을 온전히 보냅니다.

저장소: github.com/dekiengine/deki-display · 최신 릴리스: 0.40.0 · 엔진 0.40.0 이상 필요 · 의존: deki-spi, deki-gpio, deki-i2c, deki-input, deki-rendering

DekiEditor --packages-add deki-display <project> 또는 패키지 관리자로 설치합니다. 엔진 자체의 컴포넌트와 C++ API는 Deki 문서에 있습니다.

에디터에는 Display(으)로 표시됩니다.

컴포넌트

컴포넌트 카테고리 설명
DisplayPanelComponent 디스플레이 Deki 자체 디스플레이 라이브러리로 SPI, 쿼드 SPI 또는 8비트·16비트 병렬 버스를 통해 디스플레이 패널(ST7789, ILI9341, GC9A01 등)을 구동하고 엔진에 넘깁니다.
TouchPanelComponent 디스플레이 Deki 자체 디스플레이 라이브러리로 패널의 터치 컨트롤러(I2C의 GT911, CST816, FT5x06; SPI의 XPT2046)를 읽어 포인터 입력으로 사용합니다.

TouchPanelComponent

Deki 자체 디스플레이 라이브러리로 패널의 터치 컨트롤러(I2C의 GT911, CST816, FT5x06; SPI의 XPT2046)를 읽어 포인터 입력으로 사용합니다.

인스펙터 이름: 터치 패널 컴포넌트 · 카테고리: 디스플레이 · 유형: DekiDisplay::TouchPanelComponent

속성 유형 기본값 제약 설명

xMax int32 239 터치 컨트롤러가 보고하는 원시 X의 최댓값으로, 디스플레이를 회전하기 전 패널의 너비 방향 값입니다 (240x320 패널을 가로로 표시하는 경우: 239)
yMin int32 0 터치 컨트롤러가 보고하는 원시 Y의 최솟값으로, 디스플레이를 회전하기 전 패널의 높이 방향 값입니다
yMax int32 319 터치 컨트롤러가 보고하는 원시 Y의 최댓값으로, 디스플레이를 회전하기 전 패널의 높이 방향 값입니다 (240x320 패널을 가로로 표시하는 경우: 319)
offsetRotation enum "None" None, CW_90, CW_180, CW_270, Mirror, Mirror_CW_90, Mirror_CW_180, Mirror_CW_270 패널에 대한 터치 컨트롤러의 방향으로, 디스플레이 회전에 더해집니다. 컨트롤러가 패널 자체의 방향으로 좌표를 보고하면 없음입니다

변경 내역

변경 내역은 영어로 되어 있습니다.

0.40.0

Changed

  • minEngine 0.40.0: built against engine 0.40.0. A build of this package from before does not load and is rebuilt.

Fixed

  • A panel no longer goes black when the game has used up the internal RAM. The display frees its DMA bands once the panel is cleared, so a frame drawn in strips can have that RAM, and takes them back on the first present. When that RAM had gone since, every present failed and logged an error. It now takes smaller bands, down to a row, and logs a warning once; sending is a little slower with fewer rows.

0.30.3

Fixed

  • The present worker signals that it has stopped while it still holds the lock, so a display destroyed right after async present is turned off no longer races the worker's last signal.
